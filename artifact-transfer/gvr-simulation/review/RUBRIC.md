# Independent review

Review against the user's actual words and established preferences, not only against the director JSON. Score each applicable dimension 0 (fails), 1 (partial), 2 (supported), or untested. Cite exact fields or actual evidence and assign the responsible layer: director, implementation, host, tooling or unknown.

- Intent: responds to this turn; chooses appropriate create/update/none; no invented requirements represented as facts.
- Scope: preserves unaffected content and user choices; assumptions evolve without stale contradictions.
- Experience: usable persistent result rather than a film; overview reveals the whole new design; local edits stay local.
- Direction: concrete observable action, continuity, meaningful visual models, spatial legibility; prose precision without unnecessary geometry.
- Motion: content-driven timing, no default duration; proportional transitions; no compulsory long tour; interruption respects user input.
- Teaching: accurate reasoning; visual transformations carry meaning; answer disclosure is deliberate; learner can examine/replay/advance at their pace.
- Interaction: explicit outcomes and next-turn intent; direct manipulation for spatial artifacts; no inert buttons or silent button-only gesture substitution.
- Accessibility: reduced-motion and keyboard paths; readable responsive layout; accessible names even when visible text is removed.
- End-to-end fidelity: program implements director intent; limitations are not hidden behind compile success.
- Performance: measured director/implementation/first-render times, source and output bytes, repair count; unavailable values remain unknown. Distinguish playback duration from generation latency.

Final review: concrete strengths and failures, repeated patterns, layer attribution, generalizable prompt proposals, schema proposals only when prose cannot resolve the problem, bounded next experiments, and implementation capability gaps outside production director output. Do not change the prompt silently while reviewing.

Prefer actual human rendering/interaction assessment over agent aesthetic self-scoring. Report captured intent independently from execution quality. Check coherent perspective, clutter and text necessity, themed full-stage backing, and whether dragging really rotates/pans as promised. User-reported black bars are evidence; host root cause requires reproduction. See the separate human-assessment protocol.
