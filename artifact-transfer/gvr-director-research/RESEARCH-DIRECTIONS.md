# Research directions

Status checked against the frozen current skill, not inferred from conversational agreement. All experiments retain fixed prompt snapshots and compare identical user requests. Record director latency/output bytes, implementation time/repairs/source bytes, first useful render and actual visual/interaction outcomes. No target values have yet been justified.

## Suggested in chat, still absent or only partial

R1 — Meaningful visual representation (high priority; absent as an explicit rule). Define what marks stand for and why each transformation is valid. Compare algebra labelled groups with an explicit removable/restored segment model. Score understanding and mathematical correctness, not decorative motion.

R2 — Answer disclosure versus guided discovery (high; absent). Distinguish optional illustration of a complete answer from reasoning revealed through progression. Test explanatory recap and learner discovery with the same problem; verify hidden answers are genuinely hidden.

R3 — Learner pacing (high; partial). Current skill estimates reading time and mentions replayable progression, but does not explicitly separate transformation duration from time for understanding or require meaningful step controls. Compare fixed playback with pause/replay/next-step; include a five-minute explanation and a short local correction.

R4 — Interaction-to-conversation handoff (high; absent as a concrete contract). Hint, discuss and submit actions need semantic user intent plus relevant visible input. Test that the next turn receives the question and attempted answer without technical state leaking to the director. Prototype in prose behaviour before adding schema fields.

R5 — Epistemic consistency (medium; partial). Evidence tracking was cautious but response said “the gap is” after one mistake. Compare tentative diagnosis plus targeted follow-up with definitive labels. Generalize to inferred design rationales and unverified implementation claims.

## Adopted wording, still needs outcome evidence

R6 — Proportional presentation and reusable spatial taste. Compare unchanged house prompts under frozen variants; then mechanical assemblies, site layouts, charts and websites. Test for helpful introductions without universal 3D or long tours. Reference choreography is plan→assembly→reveal→inspection, not a copied roof shot or 30-second preset.

R7 — Gesture fidelity. Test pinch centre, wheel centre, selection/drag threshold, cancellation, keyboard alternatives and interruption on actual supported runtimes. Button-only substitution is not a passing gesture implementation.

R8 — Incremental state and assumptions. Run multi-turn colour, room, storey and island changes; assert unrelated design and user choices persist. Test two plausible semantic targets, failed implementation and concurrent user interactions. No fabricated bases.

R9 — Persistent surface lifecycle and responsiveness. Separate usable surface from film. Validate mobile reflow, scale/label legibility and end/interruption states. Track missing runtime support independently from director quality.

R10 — Performance versus richness. Compare frozen full prompt with a shorter modular variant, identical schema and matched tasks. Measure initial and follow-up turns separately. Simple corrections should not require a tour; complex explanations may need substantial prose. Do not equate a shorter plan with better output.

## Additional engineering research inferred from these experiments

R11 — History truth and outcome reconciliation. Test semantic completed/partial outcomes supplied through conversation against unverified director promises. Protect director isolation while preventing drift across turns. Decide how conversational history is assembled before formal schema changes.

R12 — Structured validation and repair. Repository parser handles a different director contract; create a bounded 0.4 conditional/timing validator as a separate experiment. Retain raw invalid outputs and repair counts. Test conversation-only, immediate without sequences, timed explanations, overlapping cues and zero-duration edge cases.

R13 — Context and archive integrity. Pin exact prompt versions, source hashes, turn pairing and base revision evidence. The two-storey/single-storey mismatch should be detected before implementation, without requesting runtime IDs from the user.

R14 — Reference implementation economics. From Blueprint to Home used baked projection and a host-language builder, while the implementer experiment requires direct native authoring. Compare equivalent outcomes under equal constraints; do not attribute every gap to director taste. Historical source/track/compile figures are not current controlled benchmarks.

R15 — Sound integration. Sound remains creative intent, not certified support. Recheck issue #120 and current released capabilities in a dedicated technical investigation; its live state was not checked in this review. Test synchronization separately from sound descriptions.

## Promotion criteria

Adopt a prompt change only after matched trials show improved intent/fidelity without unacceptable latency or regressions across unrelated requests. Record prompt hash, before/after examples, failure cases, decision and rollback condition. Prefer prose changes before schema expansion. Required missing runtime capability becomes development work, never a production capabilityNeeds field.

## Human-assessment additions

R16 — Projection/proportion fidelity: ground-plane continuity, plausible wall rise, aligned openings and coherent storeys; compare reference with observed near-vertical and floating-shape failures.
R17 — Focus-stage taste and speech/text allocation: minimal themed stage across structural, origami and conversational presence tasks; website counterexamples; retain meaningful dimensions/notation and accessible captions.
R18 — Deterministic full-stage backing: trace CSS/canvas clearing and test background fill without crop, distortion, stale state or generative extrapolation.
R19 — Human assessment collection and decision provenance: formalize per-turn observations, independent intent/execution judgments, cross-domain trials and reassessment.
R20 — Conversational presence ownership: host-owned audio-reactive avatar vs authored greeting; reconcile current none/no-mutation rule and verify actual speech synchronization.
