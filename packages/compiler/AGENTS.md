# @gvr/compiler

Before editing this package, read the root `AGENTS.md`, `packages/schema/capabilities/releases.json`, the current MotionScript version file, and `docs/languages/compatibility-policy.md`.

A compiler change that accepts new syntax or changes meaning is a MotionScript change: registry, tests, and version note together. A bugfix that preserves the current version's semantics does not bump the language. Accept new syntax when a modern animation construct needs it. Do not keep the 0.1 or 0.2 grammar closed.
