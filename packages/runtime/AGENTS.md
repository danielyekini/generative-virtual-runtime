# @gvr/runtime

Before editing this package, read the root `AGENTS.md`, `packages/schema/capabilities/releases.json`, the current Scene IR version file, and `docs/languages/compatibility-policy.md`.

Sampling and migration changes are Scene IR semantics. Update the registry and tests with the code. Do not reinterpret a 0.1 scene under later rules except through the documented migration. New sampling behaviour for a new capability is allowed; older programs keep the reader they were written for.
