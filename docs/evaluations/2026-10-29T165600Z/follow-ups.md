# Follow-up list

These do not change the delivered capability scope. Production code is pinned in manifest.json; preliminary failures are retained rather than marked successful.

## Confirmed defects or limitations

1. **P1 — Lottie trim wrapping/reversed endpoints and multi-shape modes.** The reference probe at 90° retains a wrapped tail that native trim clips. At 1000/1999 ms the local gate fails (a worst tile is wholly wrong), although the whole-frame hot fraction is only 0.46875%. Native reversed endpoints are empty, whereas lottie-web swaps them. Individual mode across multiple shapes is not certified. Keep the narrowed registry and approximated diagnostics; design/verify a distinct source mapping without silently changing the native reader. Preserve contour breaks in either mode.
2. **P1 — Compile latency and main-thread cancellation.** Current per-unit whole-scene clone and validation dominate medium/large compile work. Complete-file compilation remains synchronous and cannot be interrupted inside a call. Measure transaction/indexed-validation or worker options against atomic rollback and existing invalid-unit tests before changing architecture. Larger source admission addresses acceptance, not this bottleneck.
3. **P1 — Per-frame evaluation cost.** Pixels evaluates around 38 ms/frame before rendering; Square Wave reaches/exceeds the 60 Hz application budget. Repeated graph/index/ancestor work is visible in current source and prior story profiles, but this run did not collect a fresh CPU profile proving its exact share. Any topology cache must be revision-aware; sampled transforms/visibility/trim must not survive into an incompatible scene revision.
4. **P1 — Delta validation is still a structural subset.** This task fixes the demonstrably wrong wire-family reader. CREATE_SCENE/ADD_TRACKS/ADD_STEPS do not receive complete assembled-scene validation at runtime, and revision guards alone do not prove scene validity. Add adversarial, atomic replay validation separately; do not weaken rejection or treat the new replay baseline as protocol certification.
5. **P2 — Lexical token retention.** The lexer retains all emitted tokens until compiler disposal (135,073 tokens for Square Wave in the measured replay). Disposal drops them. Investigate bounded prefix compaction only with fragmentation/diagnostic-span evidence. Enlarging declaration capacity does not remove this cost.
6. **P2 — Group isolation/resources.** CanvasRenderer implements scope flags directly on the target context; no offscreen allocator exists. True overlap isolation and GPU/offscreen memory are not certified. Existing isolation registry targets remain untested; this ordering repair does not promote them. Verify an overlap fixture before a rendering-backend change.
7. **P2 — Progressive usefulness remains separate from replay validity.** These story films have no early seals. Successful simulated replay at completion does not demonstrate useful motion during source generation. The compiler freezes base definitions after its first seal. New object activation, persistent edits, drivers and interactions need explicit revision/time/channel-ownership rules; do not retrofit mutable history through this telemetry task.
8. **P3 — Build size and measurement breadth.** The playground retains its existing >500 kB bundle warning. No full Lottie corpus run, target-device matrix, forced-GC retention study, GPU completion timing or real model/network transport measurement was performed. These are explicit coverage limits, not passes.

## Hypotheses requiring new reproductions/profiles

- Revision/generation identity and cancellation/resume races may matter when a real transport is attached. Current synchronous source feeding does not test cross-generation races.
- Heap increases in some load/cancel cycles may be transient allocations or intentional source/scene retention; the unforced-GC samples do not establish a leak. Use heap snapshots and retained paths before claiming one.
- The larger positive on/off frame difference for Square Wave may combine collector cost, JIT/GC and run ordering. The fixed-cost collector microbenchmark is measured, but the paired story run is not a causal overhead decomposition.
- Source/expanded-scene limits beyond the five examined stories may still obstruct production workloads. Keep them provisional; retain a failing input and measure it before revising the next bound.
