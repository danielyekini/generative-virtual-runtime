# Native Story Cycle

The [Native Story Cycle in Notion](https://app.notion.com/p/41f0c600341a8167bea8f6d81a144341) is the canonical process. It defines the phases, ownership, human quality gates, streaming acceptance and evidence requirements. Follow its cycle links for the current corpus, capability changes and earlier cycle records.

Use the [GVR GitHub Project](https://github.com/users/danielyekini/projects/3) for live work status. The [2 November adoption decision](https://github.com/danielyekini/generative-virtual-runtime/issues/87) records the original operating direction.
