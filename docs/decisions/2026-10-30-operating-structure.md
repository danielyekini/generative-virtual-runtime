# Adopt two coordinated workstreams

Status: adopted user direction, 30 October 2026. Work item: [OPS001](https://github.com/danielyekini/generative-visual-runtime/issues/13).

Use repo-local run/orchestrator personas for Engine and Product, independent
five-terminal-run clocks, immediate same-session request intake and GitHub
Project/issues as active-work authority. Documents retain durable intent,
released semantics, consequential decisions and immutable scoped evidence.

Considered retaining the fidelity-led workflow, duplicating all task state in
Markdown, or using a single global orchestrator. Those conflict with the user's
native progressive product direction, visible issue tracking, low administration
budget and independent lane progress. The adopted structure keeps explicit
shared contracts and soft ownership, with one named owner per shared change.

No mandatory independent PR review: owning agents run the complete repository
gate, fix inherited failures, self-merge when protections permit and delete only
their own merged branches. Tests support this autonomy but do not establish every
visual/product claim; issue acceptance and actual protections remain binding.
No deployment/publication, paid provider or background runner is commissioned.

PR #11 is already merged; reuse its capacity handover rather than repeat its
optimisations or Circle evidence. E001 continues assembled-scene validation;
P001 extends existing Studio into library/editor/execute/fullscreen. Persistent
entities and real generation remain future capability work. Numeric constraint
history not documented by prior decisions remains unknown, never reconstructed
as invented intent. [Migration map](../operations/migration-map.md) limits the
supersession to active process; releases/program bytes/reports stay intact.

Revisit this operating model if concurrent claims, stale routing, review cost or
cross-lane contract conflicts produce observed failure; record the evidence and
bounded correction. A repository file is no autonomous always-on LLM runner.
