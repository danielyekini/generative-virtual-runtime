# P005 is not a gate for P007

Status/date/owner/work item: adopted user steering, 2 November 2026, Product,
[P007 #48](https://github.com/danielyekini/generative-virtual-runtime/issues/48) /
[P005 #46](https://github.com/danielyekini/generative-virtual-runtime/issues/46).

## User change

Agents already use existing Studio/engine tools during runs (engine capability
work such as planar 2.5D already produces GVR-rendered evidence). P005 only
highlights consolidating shared contracts for those tools. The user leans
against treating P005 as necessary and states the P007 dependency is not real
and may be removed. Proceed with P007; keep P005 only if it has clear later
utility.

## Decision

- Remove P005 from P007’s execution dependencies. P007 depends on **P006** only
  (model-facing reference).
- Mark P007 **Ready** and dispatch the real-model generation experiment using
  existing host/compile/runtime paths — not a new agent toolbox.
- Pin local Ollama **`qwen2.5-coder:14b`** as the integrated model for P007
  (see [2026-11-02-p007-provider-pin.md](2026-11-02-p007-provider-pin.md)).
- Keep P005 as a low-priority **Candidate** (optional consolidation/documentation
  of contracts agents already exercise). Do not block M3 generation work on it.
  No Studio chrome speculation until a future explicit need.

## Unchanged

Studio UX authority (`studio-ux.md`), P003 UX gate, P006 Done artifact, P008+
corpus prep sequencing after P007, charter vision, Engine generative-audio work.
