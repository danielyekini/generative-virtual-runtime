# Scene IR 0.10.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Documents still declare `irVersion` `"0.2"` and gate the new feature with `requiredCapabilities` containing `input.bindings`. A package that does not enable that capability rejects the scene at accept time; older validators reject the unknown `interactions` key.

## Capabilities introduced

- input.bindings

## Representation

Optional scene and `CREATE_SCENE` header field `interactions: InteractionTarget[]`:

- `nodeId` (root-scene node, unique per list), optional `pointer` (`"auto"` | `"none"`), `focusable` (boolean), `tabIndex` (integer), `bindings`.
- Binding: `on` (`click` | `activate` | `drag` | `wheel` | `key`), `key` (non-empty string, required only for `key`), optional `nodeId` (written node, default the target), `action`.
- Action: `{kind:"set", channel, value}`, `{kind:"toggle", channel, values:[a,b]}`, `{kind:"step", channel, delta, min, max}` (`min <= max`), or `{kind:"dragTranslate", min:{x,y}, max:{x,y}}` (only with `on: "drag"`, and `drag` accepts only it). Channels: `transform.position.x/y`, `transform.rotation`, `transform.scale.x/y`, `opacity` (values in `[0, 1]`).

Validation: a non-empty list requires `input.bindings`. Every written `(node, channel)` — both position axes for `dragTranslate` — is exclusively input-owned; any timeline track writing that scalar is `OVERLAPPING_WRITERS`.

## Sampling

Authored sampling is unchanged. A host input session overlays input-owned values on each sample (`InputSession.applyTo`); without a session the scene samples exactly as authored. Hit-testing reads resolved-frame draw items in logical viewport space as recorded in `docs/decisions/engine/native-input.md`.

## Readers

A 0.10 consumer accepts wire `"0.2"` documents. Migrated 0.1 scenes have no interactions.

## Not in this release

Clip/mask hit regions, multi-pointer gestures, text entry, paint-channel input targets and interaction ops inside `APPLY_ENTITY_PATCH`. Other pending ids remain outside this file.
