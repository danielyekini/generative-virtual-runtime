# Scene IR 0.16.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Documents still declare `irVersion` `"0.2"` and gate the new feature with `requiredCapabilities` containing `compositing.mask`. A package that does not enable that capability rejects the scene at accept time; older validators reject the unknown `clip` key on group compositing.

## Capabilities introduced

- compositing.mask

## Representation

Optional field `clip: { geometryId: string }` on `GroupCompositing`.

- `geometryId` names a root or composition node of kind `rectangle`, `circle`, `ellipse`, `polygon` or `path`.
- A present `clip` object requires `compositing.mask` in `requiredCapabilities`.
- Clip implies a render scope; `isolated` should be true for host opacity rules (compiler defaults it).

## Sampling

Frame sampling resolves the clip outline into the render-tree scope as
`clip: { geometry, logicalMatrix }` in viewport space. Draw items stay flat; the
renderer applies the clip per scope. Nested scopes intersect. Hit-testing walks
the render tree and rejects points outside ancestor clips. Scenes without clip
sample exactly as in 0.15.0.

## Readers

A 0.16 consumer accepts wire `"0.2"` documents. Migrated 0.1 scenes have no clips.

## Not in this release

Track mattes, alpha/luma mask modes, feathering, inverted clips, and adapter mask lowering.
