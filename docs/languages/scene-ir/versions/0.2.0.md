# Scene IR 0.2.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0, so a 0.1 consumer rejects this wire version. A 0.2 consumer loads wire `0.1` by migration and does not change 0.1 sampling, overlap rejection, the opacity product, or the flat render path.

## Capabilities introduced

- scene.migration
- timing.localScopes
- easing.cubicBezier
- easing.hold
- composition.definitions
- geometry.operators
- geometry.roundedRect
- geometry.spatialCurve
- geometry.trimPath
- paint.linearGradient
- paint.radialGradient
- resources.image
- svg.smilTimeBased
- svg.cssKeyframes
- compositing.isolatedOpacity
- compositing.blend
- effects.blur
- effects.shadow
- render.tree
- transform.parent

`text.basic` remains the 0.1.0 text node. Imports that rely on it set `requiredCapabilities` to include `text.basic`.

Cubic easing solves x, then y. Y may leave `[0, 1]`. Hold stays on the segment start until the next key. Spatial tangents are offsets from the key value; the curve uses the eased progress. `transformParentId`, when present, is the transform chain. `inheritOpacity: false` skips one ancestor in the opacity product. Trim operators apply when a path is resolved. Instances are stored and are not drawn a second time. A group with compositing becomes a nested render scope. A frame without `renderTree` stays valid.

## Readers

`migrateSceneTo02` is the only supported read of wire `0.1` by a 0.2 consumer. There is no lossless write of 0.2 back to 0.1.

## Corrections

None. A later release that corrects this file must name Scene IR 0.2.0.
