# Scene IR 0.4.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Documents still declare `irVersion` `"0.2"` and gate the new feature with `requiredCapabilities` containing `paint.gradientStroke`. A package that does not enable that capability rejects the scene at accept time.

## Capabilities introduced

- paint.gradientStroke

## Representation

`Stroke.color` may be a linear or radial gradient paint (the same `Paint` variants used for fills). Width, cap, join, and miterLimit remain on the stroke. Fill gradients do not imply stroke gradients; scenes that use a gradient on a stroke must list `paint.gradientStroke`.

The canvas renderer paints stroke gradients with the same `createLinearGradient` / `createRadialGradient` path used for fills.

## Readers

A 0.4 consumer accepts wire `"0.2"` documents. Gradient strokes require `paint.gradientStroke` in `requiredCapabilities`. Migrated 0.1 scenes do not gain gradient strokes.

Other pending ids remain outside this file. Adapter coverage is in the registry.
