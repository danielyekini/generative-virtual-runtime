# Scene IR 0.25.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0. Removes required `CompositionInstance.timingScopeId`.
The property is rejected when present (`UNSUPPORTED_PROPERTY`).
`acceptScene` / `stripInstanceTimingScopeId` strip it from older documents
(behaviour-preserving — the field was never sampled). MotionScript moves to
0.26.0 with it. No new capability token. Decision:
`docs/decisions/engine/composition-instance-timing.md` (E048 / E050).

## Representation

`CompositionInstance` fields: `id`, `definitionId`, `parentId`,
`transformParentId`, `transform`, `opacity`, `visible`, `activation`.
No `timingScopeId`.

## Migration

```
stripInstanceTimingScopeId(scene)  // drops timingScopeId from each instance
```

`acceptScene` for a `"0.2"` consumer strips before validate. Direct
`validateSceneIR` on a document that still carries the field fails honestly.

## Out of scope

Applying instance timing, composition playback, drawable expansion of
`composition.instances`.
