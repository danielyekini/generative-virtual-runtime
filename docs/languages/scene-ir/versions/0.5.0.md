# Scene IR 0.5.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Documents still declare `irVersion` `"0.2"` and gate the new feature with `requiredCapabilities` containing `geometry.animatedTrim`. A package that does not enable that capability rejects the scene at accept time.

## Capabilities introduced

- geometry.animatedTrim

## Representation

Node animation channels `trim.start`, `trim.end`, and `trim.offset` write normalised path fractions. The runtime merges sampled values over the static `geometryOperators` trim entry for that node when resolving path geometry. `geometry.trimPath` remains the static operator claim; animated channels require `geometry.animatedTrim`.

## Readers

A 0.5 consumer accepts wire `"0.2"` documents. Animated trim requires `geometry.animatedTrim` in `requiredCapabilities`. Migrated 0.1 scenes do not gain animated trim.

## Not in this release

Other pending ids remain outside this file. Adapter coverage is in the registry.
