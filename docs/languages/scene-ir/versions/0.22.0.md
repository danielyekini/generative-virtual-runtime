# Scene IR 0.22.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Documents still declare `irVersion` `"0.2"` and gate composed attachment placement with `requiredCapabilities` containing `geometry.pathSpace` (and `geometry.pathProgress` whenever `pathAttachments` is non-empty). A package that does not enable `geometry.pathSpace` samples attachments as in 0.17.0. No new field is added to `PathAttachment`. Decision: `docs/decisions/engine/path-attachment-space.md` (E039). The 0.17.0 version file stays as published.

## Capabilities introduced

- geometry.pathSpace

## Representation

Unchanged from 0.17.0. `pathAttachments` remain base definitions on the scene and on `CREATE_SCENE`, frozen after the first seal. The new capability is only a sampling gate.

## Sampling

When `geometry.pathSpace` is required, `sampleScene` still resolves the outline after morph and then trim, then maps the command point:

`parentPosition = inverse(world(traveller parent)) × world(path) × commandPoint`

`world` uses the sampled `localMatrix` (position, pivot, rotation and scale) and `transformParentId` when set, otherwise `parentId`. It does not include the camera. Attachments are applied in dependency order so a path that is itself attached is placed before travellers that use its transform. The written value is `transform.position`. When `orient` or `rollRadius` is set, rotation is the angle of the tangent after that same matrix, plus command-space `distance / rollRadius`. `orient` alone is never rolling. `rollRadius` does not grow when the path is scaled.

A scene that does not require `geometry.pathSpace` writes the command point straight into `transform.position`, as 0.17.0 specifies. An identity path transform and a shared transform parent produce the same position either way.

The traveller and the path must share a root space (`world` or `screen`). A mismatch records `SPACE_VIOLATION` and leaves the pose authored. A singular parent matrix or a degenerate oriented tangent records `RUNTIME_DEGRADED`. A dependency cycle records `CYCLE` and leaves those poses authored. Missing nodes are skipped, as in 0.17.0. `ResolvedFrame` is unchanged.

## Authoring gates assessment

1. **Simplicity.** No arc-length tables and no extra parent whose only job is to keep the path transform neutral.
2. **Generation.** Additive capability token on the existing attachment. Old Scene IR without the token does not move.
3. **Streaming.** Sample-time composition. Sealed attachment lists are not rewritten when a transform track arrives.
4. **Expressiveness.** Pivot, rotation and non-uniform scale stay in `localMatrix`. The traveller's own pivot is not solved away.

## Readers

A 0.22 consumer accepts wire `"0.2"` documents. Older readers reject the unknown capability token. Migrated 0.1 scenes have no attachments.

## Not in this release

A standalone `transform.autoOrient` channel, stroke width profiles, and adapter lowering from Lottie or SVG.
