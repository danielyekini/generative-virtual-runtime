# Scene IR 0.1.0

Published. Do not edit. Wire version `"0.1"`.

This release is the first Scene IR. `packages/schema/src/types.ts` and the validator are the representation. `packages/schema/CONTRACT.md` is a reading of that representation and does not add support the registry does not list.

## Capabilities introduced

- scene.camera
- scene.contain
- geometry.primitives
- geometry.path
- text.basic
- easing.named
- animation.tracks
- animation.steps
- animation.expressions
- hierarchy.opacity

Ids are `parent.child`. Names contain no dots. Opacity of a drawn node is the product of ancestors. The default render is a flat list of draw items. Sampling does not overwrite authored base values.

## Readers

A 0.1 consumer accepts wire `0.1` only.
