# Scene IR 0.24.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for new representation and sampling rules. Documents
still declare `irVersion` `"0.2"` and gate the new fields with
`requiredCapabilities` containing `resources.imageSampling` and/or
`resources.spriteFrames`. Decision: `docs/decisions/engine/resource-lifecycle.md`
(E019, implemented by E045). MotionScript 0.25.0 is the matching source release.

## Capabilities introduced

- resources.imageSampling
- resources.spriteFrames

## Representation

- `ImageNode.sampling?: "smooth" | "pixelated"` (`resources.imageSampling`).
- `ImageResource.frames?: { columns, rows }`. Each count is an integer from 1 to
  1024 (`resources.spriteFrames`).
- `ImageNode.frame?`: an integer `0 ≤ frame < columns × rows` that requires a
  `frames` grid on the node's resource (`resources.spriteFrames`).
- New node channel `frame` (number, track). It may target only an image node
  whose resource has a grid. Without the capability it is `MISSING_REQUIRED`.
- Resolved image geometry gains `sampling?` and
  `frame?: { column, row, columns, rows }`. The frame is present only when the
  resource has a grid.
- Each field or channel without its capability is `MISSING_REQUIRED`. A bad
  grid or frame is `INVALID_GEOMETRY`. A frame track on an image without a
  grid is `INVALID_TRACK_TARGET`.

## Sampling

The frame value is the sampled `frame` channel when one is active, and
`ImageNode.frame ?? 0` otherwise. It becomes the cell index
`clamp(floor(value + 1e-9), 0, columns × rows − 1)`. A non-finite value shows
cell 0. The index is row-major: `column = index mod columns`,
`row = floor(index / columns)`. Renderers draw the source rectangle
`(column × w / columns, row × h / rows, w / columns, h / rows)` of the decoded
`w × h` image at the node size. A node's `sampling` overrides the renderer
default for that draw.

Scenes without these fields resolve and draw exactly as `resources.image`.
