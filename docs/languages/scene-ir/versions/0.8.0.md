# Scene IR 0.8.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Documents still declare `irVersion` `"0.2"` and gate the new feature with `requiredCapabilities` containing `paint.animatedSolid`. A package that does not enable that capability rejects the scene at accept time.

## Capabilities introduced

- paint.animatedSolid

## Representation

Node animation channels `fill.r`, `fill.g`, `fill.b`, `fill.a`, `stroke.r`, `stroke.g`, `stroke.b`, `stroke.a`, and `stroke.width` write solid paint components and uniform stroke width. The runtime merges sampled values over the authored solid fill/stroke on that node when resolving appearance. Gradient paints are left unchanged when a track targets fill/stroke colour channels. Node opacity remains independent of paint alpha.

## Readers

A 0.8 consumer accepts wire `"0.2"` documents. Animated solid paint requires `paint.animatedSolid` in `requiredCapabilities`. Migrated 0.1 scenes do not gain these channels.

## Not in this release

Other pending ids remain outside this file. Adapter coverage is in the registry. Whole-colour value types and gradient-stop animation remain open.
