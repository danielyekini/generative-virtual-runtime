# Scene IR 0.11.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Documents still declare `irVersion` `"0.2"` and gate the new feature with `requiredCapabilities` containing `audio.cues`. A package that does not enable that capability rejects the scene at accept time; older validators reject the unknown resource kind, `audioCues` key and `ADD_AUDIO_CUES` op.

## Capabilities introduced

- audio.cues

## Representation

- Resource kind `audio`: `{ id, kind: "audio", href, durationMs, readiness? }`, `href` non-empty, `durationMs` the positive decoded length.
- Optional scene field `audioCues: AudioCueDefinition[]` (not part of the `CREATE_SCENE` header): `{ id, resourceId, bus, startMs, offsetMs?, durationMs?, loops?, gain?, fadeInMs?, fadeOutMs?, required? }`. `bus` is `"narration" | "effects" | "music"`; `startMs` in `[0, timeline.durationMs]`; `offsetMs < resource.durationMs`; `offsetMs + durationMs <= resource.durationMs`; `loops` integer in `[1, 1000]`; `gain` in `[0, 4]`; fades non-negative; ids unique; at most 4096 cues.
- Delta op `{ op: "ADD_AUDIO_CUES", cues }` appends cues. It may follow the first seal; every cue must start at or after the seal frontier at its position in the transaction.

Validation: any audio resource or non-empty `audioCues` requires `audio.cues`. `acceptScene` rejects pending/failed audio resources only when a required cue (explicit `required`, else narration) uses them.

## Sampling

Visual sampling is unchanged. Audio is a pure schedule over scene time: span = play length × loops, linear fades, narration ducks effects/music by a step gain. Hosts reconcile it with `AudioSession.sync`; `mixAudio` exports the same function. See `docs/decisions/engine/audible-media-clock.md`.

## Readers

A 0.11 consumer accepts wire `"0.2"` documents. Migrated 0.1 scenes have no audio.

## Not in this release

Spatial audio, ducking ramps, per-cue rate, timing-scope-relative cues and audio ops inside `APPLY_ENTITY_PATCH`. Other pending ids remain outside this file.
