# Scene IR 0.20.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Documents still declare `irVersion` `"0.2"` and gate measured text boxes with `requiredCapabilities` containing `text.layoutMetrics`. A package that does not enable that capability keeps the legacy 0.6em text box. Decision: `docs/decisions/engine/dynamic-text-and-metrics.md` (E041).

## Capabilities introduced

- text.layoutMetrics

## Representation

No new scene fields. A scene opts in by listing `text.layoutMetrics` in `requiredCapabilities`.

Frame resolution sets `ResolvedFrame.textLayoutMetrics` when that capability is required. The flag is omitted otherwise, so older frames keep their shape.

## Sampling

When the flag is set, text hit-testing and spatial outlines use `measureTextLine` on the sampled string:

- Width is the sum of builtin `sans` advances. Unlisted code points and other families use 0.6em.
- Ascent is `0.8 × font.size` and descent is `0.2 × font.size`.
- The local AABB follows `align` (`left`, `center`, `right`) and `baseline` (`alphabetic`, `top`, `middle`, `bottom`).

A host `measureText` callback replaces that box for hit-testing. Spatial outlines stay on the builtin table. Scenes without the capability sample text boxes exactly as in 0.19.0.

Builtin font resources (`source: "builtin"`) are ready in-process. This release does not hold a frame for a font fetch.

## Authoring gates assessment

1. **Simplicity.** The capability token is the whole opt-in. The runtime measures the line.
2. **Generation.** Additive on scenes that already carry `requiredCapabilities`.
3. **Streaming.** Boxes follow the sampled string, including numeric and stepped content. No retained metric buffer crosses a seal.
4. **Expressiveness.** Align and baseline boxes are derived. Custom fonts, wrapping and per-glyph transforms stay outside this release.

## Readers

A 0.20 consumer accepts wire `"0.2"` documents. Migrated 0.1 scenes have no layout-metrics flag and keep the legacy estimate.

## Not in this release

Custom font URLs and load holds, `text.animators`, wrapping / multi-line text, billboard labels, and adapter lowering of foreign font metrics.
