# Scene IR 0.9.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 paired with MotionScript 0.9.0. **No new Scene IR
operations or sampling rules.** Declarative MotionScript statements lower onto
existing `APPLY_ENTITY_PATCH` ops introduced in 0.6.0 / 0.7.0.

## Capabilities completed

- entities.durableRevisions
- entities.drawableBindings

## Representation

Unchanged from 0.6.0 / 0.7.0. Documents still declare `irVersion` `"0.2"` and
gate with `requiredCapabilities` containing the entity capability tokens.

## Readers

A 0.9 consumer accepts wire `"0.2"` documents with the same entity-patch
admission rules as 0.7. Migrated 0.1 scenes do not gain entity patches.

## Not in this release

Other pending ids remain outside this file.
