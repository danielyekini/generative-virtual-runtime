# Scene IR 0.23.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new representation and sampling rule. Documents
still declare `irVersion` `"0.2"` and gate cyclic timing with
`requiredCapabilities` containing `timing.cyclicScopes`. Decision:
`docs/decisions/engine/time-composition.md` (E014, implemented by E043).
MotionScript 0.24.0 is the matching source release.

## Capabilities introduced

- timing.cyclicScopes

## Representation

- `TimingScope` gains optional `periodMs` (finite, > 0) and `repeat` (an
  integer in 1..10 000 that requires `periodMs`).
- `StepDefinition` gains optional `timingScopeId`. Its chain must contain a
  period, and `timeMs` is then local to that scope.
- Either key without `timing.cyclicScopes` is `MISSING_REQUIRED`. Bad domains
  are `INVALID_TIMING`. Scopes still arrive on `CREATE_SCENE`, and steps still
  arrive with `ADD_STEPS`.

## Sampling

Scope chains map root to leaf. An affine scope maps `(parent − offsetMs) /
stretch`, as in `timing.localScopes`. A cyclic scope then wraps that value
(`cyclicLocalTimeMs`):

- **No `repeat`.** `wrap(affine, periodMs)` into `[0, periodMs)`, on both sides
  of the offset.
- **`repeat` N.** If `affine < 0` the scope is not entered. If
  `affine ≥ N × periodMs` the time is pinned at `periodMs`. Otherwise it wraps.
  Below an unentered finite repeat, the whole chain is not entered (−∞), so a
  nested cycle cannot wrap negative time back into activity.

Tracks use the resulting local time for the existing active, hold and fill
rules. Expressions get `local_t` / `progress` from it, and `t` stays absolute.

A cyclic step resolves to the last step at or before the local time. Before a
cycle's first step, the previous cycle's final step carries over. Before the
first cycle of a finite repeat, the step contributes nothing. At a held seal
frontier, a step exactly at the frontier's local instant is excluded, as root
steps are.

## Validation

- A track or step in a cyclic chain lies inside `[0, periodMs]` of its
  innermost cycle, mapped through the affine scopes below it. Root-span
  duration checks do not apply to it.
- Track overlap is checked per cycle in that cycle's local frame.
- A channel written in a cyclic chain is owned by it. Any root or affine track,
  root step, or writer in another cycle on the same scalar is
  `OVERLAPPING_WRITERS`.

## Streaming admission

A track or step whose chain contains a period is admitted only while the sealed
frontier is at or before the chain's entry (`cyclicWriterAdmissible`). The
entry is the root time of local 0 through the first cycle of each finite
repeat. It is −∞ for an unbounded cycle or a cycle under negative stretch. A
frontier of 0 (no seal yet) admits every writer.

## Readers

A 0.23 consumer accepts wire `"0.2"` documents. Scopes without `periodMs`
sample exactly as in 0.22.0. Older readers reject the unknown capability token
and the `periodMs`, `repeat` and step `timingScopeId` keys. Migrated 0.1 scenes
have no cyclic scopes. `ResolvedFrame` is unchanged.

## Not in this release

- cyclic timing for composition instances;
- scene-level looping;
- time-varying periods;
- importer lowering of Lottie loops or SVG `repeatCount`.
