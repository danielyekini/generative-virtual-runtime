# Scene IR 0.3.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Documents keep `irVersion: "0.2"` and gate the feature with `requiredCapabilities: ["geometry.pathMorph"]`. A package that does not enable that capability rejects the document at accept time.

## Capabilities introduced

- geometry.pathMorph

## Representation

- `NodeAnimChannel` includes `commands` on `kind: "path"` nodes.
- `KeyframeTrack.valueType` may be `"path"`.
- Keyframe `value` is a `PathCommand[]` with the same topology across the track (identical `cmd` sequence).
- Spatial tangents are not used on path tracks.
- Sampling applies segment easing, then component-wise lerps matching commands. `Z` stays `Z`. Morph samples are applied before geometry operators such as trim.

## Readers

`migrateSceneTo02` is unchanged for wire `0.1`. Path morph tracks do not appear on migrated 0.1 scenes. A consumer without `geometry.pathMorph` enabled rejects scenes that list it in `requiredCapabilities`.

## Corrections

None. A later release that corrects this file must name Scene IR 0.3.0.
