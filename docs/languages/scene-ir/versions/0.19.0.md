# Scene IR 0.19.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Documents still declare `irVersion` `"0.2"` and gate the new feature with `requiredCapabilities` containing `compositing.matte`. A package that does not enable that capability rejects the scene at accept time; older validators reject the unknown `matte` key on group compositing and on render-tree scopes. Decision: `docs/decisions/engine/track-mattes.md` (E036).

## Capabilities introduced

- compositing.matte

## Representation

Optional field on group compositing:

```ts
matte?: { nodeId: string };
```

- A present `matte` object requires `compositing.matte` in `requiredCapabilities`.
- `nodeId` names a node in the same scene that is outside the matted group (not itself, an ancestor, or a descendant). Following `matte.nodeId` must not cycle.
- Matte implies an isolated compositing scope when isolation was not already set.

## Sampling

Frame resolution attaches a coverage tree to the render-tree scope:

```ts
matte?: RenderTreeNode;
```

The coverage tree is the source node and the descendants that are themselves visible, including a source the author marked `visible false`. Draw items in the main list stay unchanged: a hidden source does not paint there. The renderer draws the scope into an offscreen buffer, draws the coverage tree into a second buffer, and keeps content pixels with `destination-in`. If a buffer cannot be allocated, the scope is withheld. Scenes without `matte` sample exactly as in 0.18.0.

Hit-testing walks that coverage tree with the same painted-geometry rules as other leaves. Node opacity must be greater than zero. Partial fill alpha is not sampled.

## Authoring gates assessment

1. **Simplicity.** The id is the whole contract; the runtime samples ink.
2. **Generation.** Additive on existing group compositing.
3. **Streaming.** Resolution is per assembled scene. No retained mask buffer crosses a frame.
4. **Expressiveness.** Group, text and image sources are legal. Luma, invert and feather stay outside this release.

## Readers

A 0.19 consumer accepts wire `"0.2"` documents. Migrated 0.1 scenes have no mattes.

## Not in this release

Luma and inverted mattes, a feather property, and adapter lowering from Lottie `tt` or SVG masks.
