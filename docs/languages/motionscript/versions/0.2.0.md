# MotionScript 0.2.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0, so this is a breaking change for a 0.1 compiler. A 0.1 program is still valid 0.1 and is not read as 0.2. New syntax requires `version "0.2"` and a `requires` list for the capabilities the program uses.

## Capabilities introduced

- scene.migration
- timing.localScopes
- easing.cubicBezier
- easing.hold
- composition.definitions
- geometry.operators
- geometry.roundedRect
- geometry.spatialCurve
- geometry.trimPath
- paint.linearGradient
- paint.radialGradient
- resources.image
- svg.smilTimeBased
- svg.cssKeyframes
- compositing.isolatedOpacity
- compositing.blend
- effects.blur
- effects.shadow
- render.tree
- transform.parent

`text.basic` stays the 0.1.0 text capability. A 0.2 program that needs the capability token names `text.basic` in `requires`.

Cubic easing is `ease cubic(x1, y1, x2, y2)` with x controls in `[0, 1]`. Hold easing is `ease hold`. Spatial tangents are per-key offsets on a vec2 track. A 0.1 compiler rejects these forms.

## Readers

A 0.2 compiler accepts 0.2 programs. It does not rewrite a 0.1 program into 0.2 semantics. There is no lossless down-conversion to 0.1.0.

## Not in this release

The pending note lists constructs that are still outside the language. This file does not claim importer coverage. Adapter status is in the registry.
