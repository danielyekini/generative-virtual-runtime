# MotionScript 0.1.0

Published. Do not edit. Wire version `"0.1"`.

This release is the first MotionScript. The grammar in `packages/schema/src/grammar.ts` is the syntax. A 0.1 program compiles to Scene IR 0.1.0.

## Capabilities introduced

- scene.camera
- scene.contain
- geometry.primitives
- geometry.path
- text.basic
- easing.named
- animation.tracks
- animation.steps
- animation.expressions
- hierarchy.opacity

Named easing is `linear`, `easeIn`, `easeOut`, and `easeInOut`. Time in the language uses durations; the compiled IR uses milliseconds. Angles in the language use degrees; the IR uses radians.

## Readers

A 0.1 compiler rejects 0.2 syntax. See MotionScript 0.2.0.
