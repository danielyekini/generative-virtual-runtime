# MotionScript 0.25.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for new syntax and semantics. Scene IR moves to 0.24.0
with it, because image nodes, image resources and a new `frame` channel change
the validated representation and the sampling rules. Programs still declare
`version "0.2"`. When an image declares `sampling`, the compiler adds
`resources.imageSampling`. When it declares `frames`, the compiler adds
`resources.spriteFrames`. Decision: `docs/decisions/engine/resource-lifecycle.md`
(E019, implemented by E045).

## Capabilities introduced

- resources.imageSampling
- resources.spriteFrames

## Syntax

```
image Walker {
  href "images/walker-atlas.png";
  size (96, 96);
  sampling pixelated;     // or smooth
  frames (4, 2);          // atlas grid: 4 columns, 2 rows
  frame 0;                // optional static cell, row-major from the top left
  position (40, 60);
};
animate Walker.frame { from 0; to 8; duration 800ms; };
```

- `sampling smooth|pixelated;`, `frames (columns, rows);` and `frame <n>;` are
  image-node properties. Using them on another node kind is an error.
- `frames` counts are whole numbers from 1 to 1024. `frame` is a whole number
  from 0 to `columns × rows − 1` and needs `frames`.
- `sampling`, `frames`, `frame`, `smooth` and `pixelated` match by spelling.
  They are not reserved words, so nodes with those names still compile.
- `frame` is an ordinary number channel. It works with `animate`,
  `keyframes`, timed keys, beats, and local and cyclic `timing` scopes on an
  image that declares `frames`.

## Semantics

- The sampled `frame` value is floored, then clamped to the grid. A track
  `from 0; to N; duration D;` therefore shows N cells for `D / N` each and then
  holds the last cell. Inside a `period D` cycle it loops.
- The renderer derives each cell rectangle from the decoded image size, so
  authors name a grid and an index and do no source-pixel arithmetic. The
  cell is drawn at the node's `size`.
- A node's `sampling` overrides the host renderer default. Omitting it keeps
  that default, so 0.24 programs draw exactly as before.

## Language change gate

- **Authoring simplicity:** a grid and an index replace source rectangles and
  per-frame `step` lists. One `animate … from 0; to N` plays a strip.
- **Generation friendliness:** a model varies frame counts, speeds and phases
  with existing track and cycle syntax, and invents no new micro-syntax. A bad
  index or grid is a plain compile error.
- **Streaming:** `frame` follows the ordinary seal rules. A frame track that starts behind the seal is `INVALID_TIMING`
  / `SEALED_HISTORY_WRITE`. Image loading is host readiness, not a timeline
  concern: required images hold startup (E019).
- **Expressiveness vs computation:** the compiler and renderer own cell
  geometry and floor/clamp, which keeps author arithmetic low.

## Out of scope

Per-cell sizes, padding, trimmed or packed atlases, frame-rate sugar, image
pattern paint (E046), web fonts, and Lottie or SVG import.
