# MotionScript 0.5.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "geometry.animatedTrim"`. A package that does not enable that capability rejects the document at accept time. A 0.4.0 package without the capability does not accept animated trim tracks.

## Capabilities introduced

- geometry.animatedTrim

## Syntax

Path nodes may animate trim window channels:

```
keyframes Path1.trim.end {
  start 0ms;
  duration 1000ms;
  0% 0;
  100% 1;
};
```

`trim.start`, `trim.end`, and `trim.offset` are normalised path fractions. Static `operators { trim …; }` remains the authored base; tracks override sampled values. Fill gradients and stroke gradients are unchanged.

## Readers

A 0.5 consumer accepts wire `"0.2"` documents. Animated trim requires `geometry.animatedTrim` in `requires`. There is no lossless down-conversion that drops animated trim into a single static operator.
