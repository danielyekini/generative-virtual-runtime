# MotionScript 0.14.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "space.planarSeams"` (the compiler adds it when a `spatialLayer` with a `seams` block lowers, alongside `space.planar25d`). A package that does not enable that capability rejects the document at accept time. Decision: `docs/decisions/engine/seam-depth-order.md` (E016); versioning E030.

## Capabilities introduced

- space.planarSeams

## Syntax

No new reserved words. `seams` is a new item inside a `spatialLayer` body; it and its body words (`split`, `epsilon`, `maxFragments`, `edge`) are matched by spelling and stay usable as identifiers elsewhere.

```
spatialLayer card {
  camera { projection perspective; };
  surface Base { };
  surface Flap {
    parent Base;
    hinge (480, 110) (480, 250) -0.9;
  };
  seams {
    split true;
    epsilon 0.001;
    maxFragments 16;
    edge Base Flap;
  };
};
```

- `seams { … };` at most once per `spatialLayer`. An empty block opts in with the defaults.
- `split true|false;` splits true surface intersections into ordered fragments (default `true`).
- `epsilon n;` view-space tolerance, in logical units, for declared seam edges. Must be greater than 0 (default 0.001).
- `maxFragments n;` extra draw items splitting may add to the layer per frame: an integer from 0 to 1024 (default 64).
- `edge <surface> <surface>;` declares a seam between two different surfaces of the same layer. Unknown surfaces report `UNKNOWN_TARGET`; a pair is declared at most once.

## Semantics

Plane tests (E010) stay the occlusion authority. With seams, a pair of surfaces that straddle each other's planes is clipped along the exact plane–plane intersection, and each part paints in the order the same plane tests give it. Fragments keep the surface's node id, appearance and hit target. Text, image, open-outline and stroked surfaces are not split. Pairs over the fragment budget are not split either. Both cases keep the 0.12.0 intersection warning. A declared seam whose surfaces no longer share an outline edge in view space is reported, not repaired. Runtime details follow `@gvr/runtime` `projectSpatialFrame` and the E016 decision.

## Readers

A 0.14 consumer accepts wire `"0.2"` documents. Seams require `space.planarSeams` in `requires`. Older packages reject `seams` as an unknown spatialLayer item. Programs without it compile exactly as in 0.13.0, including identifiers spelled like seams body words.

## Not in this release

Authored or animated paint-order channels (hosts may pass tie-break hints), boolean union of surfaces, curved-surface intersections, near-plane clipping and splitting of stroked or text surfaces. Other pending ids remain outside this file.
