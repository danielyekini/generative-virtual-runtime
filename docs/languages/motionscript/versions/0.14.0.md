# MotionScript 0.14.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "audio.generative"` (the compiler adds it, with `audio.cues`, when a generative audio declaration or sugar lowers). A package that does not enable that capability rejects the document at accept time. Decision: `docs/decisions/engine/generative-audio-contract.md` (E031); runtime provider E032; language E033.

## Capabilities introduced

- audio.generative

## Syntax

No new reserved words. Existing `audio` / `cue` remain reserved. `speech`, `effect`, `narration`, `effects`, `voice`, `loop`, `seed`, `stability`, `similarity` and `speed` match by spelling and stay usable as identifiers elsewhere.

Href form (unchanged from 0.11.0):

```
audio Voice "lesson/voice.wav" 4.2s;
cue Intro narration Voice at 0ms;
```

Explicit generative form:

```
audio Hello = speech "This is an example of what I sound like";
cue N1 narration Hello at 0ms;

audio Tracks = effect "Train tracks" { duration 3s; loop; voice "rails"; seed 1; stability 0.4; };
cue E1 effects Tracks at 1200ms;
```

Authoring sugar (anonymous generative resource + cue):

```
audio.narration("This is an example of what I sound like");
audio.effects("Birds tweeting", duration 2s) at 500ms;
```

- `audio <id> = speech|effect "<prompt>" [{ … }];` declares a generative resource. Body: `duration` (hint), `voice` (string), `loop` / `loop true|false`, `seed`, `stability` / `similarity` / `speed`. Resources are base definitions, frozen after the first `seal`. Provisional `durationMs` is estimated from the hint or prompt length.
- `audio.narration("<prompt>" [, args…]) [at <time>];` / `audio.effects(...)` emit a `GenNarrationN` / `GenEffectsN` resource plus a cue on the matching bus (narration required by default; effects optional). Sugar args are comma-separated key/value pairs (no colon token).
- Cues are unchanged (`audio.cues`). Generative programs require both `audio.generative` and `audio.cues`.

## Semantics

Hosts synthesise through `GenerativeAudioProvider` and revise resource duration without moving scene time (E032). Fixture providers keep CI offline. Export of required generative cues waits until those resources are ready.

## Readers

A 0.14 consumer accepts wire `"0.2"` documents. Generative audio requires `audio.generative` (and `audio.cues`) in `requires`. Older packages reject generative constructs. Href-only programs compile exactly as in 0.13.0.

## Not in this release

Live ElevenLabs network calls (E034 adapter), Studio credential UX, music generation, alignment-driven captions, and WebSocket streaming TTS. Other pending ids remain outside this file.
