# MotionScript 0.21.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate dashed strokes with `requires "paint.strokeDash"`. A package that does not enable that capability keeps solid strokes. Decision: `docs/decisions/engine/path-progress-geometry-authoring.md` (E038).

## Capabilities introduced

- paint.strokeDash

## Syntax

`dash` and `phase` are not reserved words. They match by spelling at the end of an existing stroke value. Phase is legal only after a dash list:

```
scene "marks" {
  version "0.2";
  viewport (640, 360);
  background #0b1220;
  duration 2s;
  requires "paint.strokeDash";
};
line Wire {
  from (80, 180);
  to (560, 180);
  stroke #f8fafc width 6 dash (18, 10) phase 0;
};
keyframes Wire.stroke.phase {
  start 0ms;
  duration 2s;
  0% 0;
  100% 28;
};
```

A solid stroke that omits `dash` compiles exactly as in 0.20.0 and does not require this capability.

## Semantics

`dash` is one or more positive finite lengths in local geometry units. `phase` is the pattern offset in those same units. Positive phase advances into the pattern. Omitted phase is 0. `animate` / `keyframes` on `Node.stroke.phase` samples that offset, and the node must already have a dash. Dashes do not replace trim.

## Authoring gates assessment

1. **Simplicity.** Lengths and a phase are written on the stroke the author already has. No arc-length table and no extra nodes.
2. **Generation.** Models already emit `stroke` and `requires`. The dash list is a parenthesised number list, the same shape as other tuples.
3. **Streaming.** Phase is an ordinary numeric channel on a sealed timeline. The pattern does not allocate geometry as time advances.
4. **Expressiveness.** The renderer owns the dash. Authors do not emit on/off subpaths. Trim, path progress and variable width stay separate.

## Readers

A 0.21 consumer accepts wire `"0.2"` documents. Dashed strokes require `paint.strokeDash` in `requires`. Older packages reject the capability token, the `dash` and `phase` fields, and the `stroke.phase` channel. Programs without a dash keep solid strokes.

## Not in this release

Variable width profiles, using dashes as a substitute for trim, the geometry `dashCommands` prototype as a paint claim, and Lottie or SVG dash import.
