# MotionScript 0.3.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "geometry.pathMorph"`. A package that does not enable that capability rejects the document at accept time. A 0.2.0 package without the capability does not read path morph tracks.

## Capabilities introduced

- geometry.pathMorph

## Syntax

Keyframe and animate values may be path literals:

```
path { move (0, 0); cubic (10, 0) (10, 10) (0, 10); close; }
```

The target channel is `commands` on a `path` node. Every keyframe value must share the same command topology (same length and `cmd` sequence). Spatial tangents are forbidden on path keys. Sampling lerps numeric fields of matching commands; `close` stays `close`.

## Readers

A 0.3 consumer accepts wire `"0.2"` documents. Path morph requires `geometry.pathMorph` in `requires`. There is no lossless down-conversion that drops morph tracks into 0.2.0 without the capability.
