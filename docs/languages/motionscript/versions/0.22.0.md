# MotionScript 0.22.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"`. `attach` is unchanged. The compiler adds `requires "geometry.pathSpace"` beside `geometry.pathProgress` when it lowers an attachment. A package that does not enable `geometry.pathSpace` keeps the 0.17 path-local placement. Decision: `docs/decisions/engine/path-attachment-space.md` (E039). This names the sampling rule in Scene IR / MotionScript 0.17.0 and does not edit that file.

## Capabilities introduced

- geometry.pathSpace

## Syntax

No new productions and no new reserved words. `attach`, `along`, `progress`, `orient` and `rollRadius` stay as in 0.17.0.

```
scene "rider" {
  version "0.2";
  viewport (640, 360);
  background #0b1220;
  duration 4s;
  requires "geometry.pathProgress";
  requires "geometry.pathSpace";
};
group Wagon {
  position (80, 180);
  path Rail { stroke #38bdf8 width 4; move (0, 0); line (200, 0); };
};
circle Tip { radius 8; fill #fbbf24; };
attach Tip along Wagon.Rail { progress 1; orient true; };
```

The compiler inserts `geometry.pathSpace` for every `attach`, including programs whose source `requires` list names only `geometry.pathProgress`. Recompiling a 0.17 program therefore follows the path node's transform. Stored Scene IR that does not list the new capability does not.

`attach` is rejected when the traveller and the path resolve to different root spaces (one `screen`, one `world`).

## Semantics

See the Scene IR 0.22.0 note. Authors write the same `attach` statement. Moving, rotating or scaling the path, or placing the traveller under a different parent, keeps the traveller on the drawn stroke.

## Authoring gates assessment

1. **Simplicity.** The statement stays one progress number. Authors do not wrap the rail in an identity-transform parent just to move it.
2. **Generation.** The same `attach` line. Models stop inventing a shared parent to cancel a transform.
3. **Streaming.** Attachments remain base definitions. Late transform, morph and trim deltas recompute the pose at sample time.
4. **Expressiveness.** The matrix stays in the runtime. `rollRadius` stays command-space arc length.

## Readers

A 0.22 consumer accepts wire `"0.2"` documents. Older readers reject the unknown capability token. They still accept a 0.17 scene that requires only `geometry.pathProgress`.

## Not in this release

A standalone `transform.autoOrient` channel, stroke width profiles, and adapter lowering from Lottie or SVG.
