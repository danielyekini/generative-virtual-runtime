# MotionScript 0.20.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate measured text boxes with `requires "text.layoutMetrics"`. A package that does not enable that capability keeps the legacy 0.6em text box. Decision: `docs/decisions/engine/dynamic-text-and-metrics.md` (E041).

## Capabilities introduced

- text.layoutMetrics

## Syntax

No new productions and no new reserved words. Authors opt in with the existing `requires` statement:

```
scene "labels" {
  version "0.2";
  viewport (640, 360);
  background #0b1220;
  duration 2s;
  requires "text.layoutMetrics";
};
text Title {
  position (320, 180);
  content "GO";
  fontSize 48;
  align center;
  baseline middle;
  fill #f8fafc;
};
```

Programs that omit the requirement compile exactly as in 0.19.0.

## Semantics

Builtin family `sans` is ready without a host. Hit targets and spatial text outlines use the in-process advance table (`measureTextLine`) for the sampled string, including `align` and `baseline`. Other families use a 0.6em advance. A host `measureText` callback may override that box; conformance of `sans` programs does not require it.

## Authoring gates assessment

1. **Simplicity.** One `requires` line. Authors do not compute glyph widths; the runtime derives the align and baseline box.
2. **Generation.** Models already emit `requires` and `text` nodes. No per-glyph micro-syntax.
3. **Streaming.** Measurement is a pure function of the sampled string, font, align and baseline. Seals and late content steps do not retain a font buffer.
4. **Expressiveness.** Advance, ascent and descent stay in the metric table. Per-glyph motion, wrapping and custom font files stay out.

## Readers

A 0.20 consumer accepts wire `"0.2"` documents. Measured boxes require `text.layoutMetrics` in `requires`. Older packages reject the capability token. Programs without it keep the legacy em-box.

## Not in this release

Custom font URLs and load holds, `text.animators`, wrapping / multi-line text, billboard labels, and Lottie/SVG text-metric import.
