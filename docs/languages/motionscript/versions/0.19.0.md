# MotionScript 0.19.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "compositing.matte"` (the compiler adds it when a group carries `matte`). A package that does not enable that capability rejects the document at accept time. Decision: `docs/decisions/engine/track-mattes.md` (E036).

## Capabilities introduced

- compositing.matte

## Syntax

`matte` is a new reserved word used as a group property. Matte source ids stay ordinary identifiers.

```
group Card {
  matte Window;
  rectangle Panel { size (280, 160); fill #38bdf8; };
};
group Window {
  visible false;
  circle Left { position (70, 80); radius 48; fill #ffffff; };
  text Word { position (140, 88); content "GO"; fontSize 36; align center; fill #ffffff; };
};
```

- `matte <nodeId>;` on a `group` at most once (last write wins like other props).
- Implies a compositing scope; `isolated` defaults to true when omitted (same pattern as `clip`, blend and blur).
- The source may be any node outside the matted group, including a group of ordinary shapes, text, or an image. It must not be the group itself, an ancestor, or a descendant. Matte cycles are rejected.
- Dedicated matte sources usually set `visible false` so they do not also paint; a visible source still paints in order and is sampled.

## Semantics

The group's render scope keeps descendant pixels only where the source node's painted alpha is. The source is sampled with its subtree, opacity, text, images, gradients and any blur already on that subtree. Nested `clip` on the matted group still intersects. Hit-testing requires painted-geometry coverage of the matte source (node opacity greater than zero). Partial fill alpha is visual only; it does not punch holes in hits.

## Authoring gates assessment

1. **Simplicity.** One keyword and a node id. Authors build the window from ordinary shapes and text instead of boolean-merging an outline.
2. **Generation.** Additive on groups models already emit. `matte Window;` is a short line beside `visible false` on the source.
3. **Streaming.** The id resolves against the assembled scene. A missing source fails closed. Buffers are per frame, not retained across seals or cancellation.
4. **Expressiveness.** Painted alpha (including a fading group) is the system's job. Luma, invert and a separate feather property stay out; existing `blur` on the source softens the ink.

## Readers

A 0.19 consumer accepts wire `"0.2"` documents. Matte requires `compositing.matte` in `requires`. Older packages reject the capability token and the unknown `matte` compositing field. Programs without it compile exactly as in 0.18.0, except that `matte` is now reserved and cannot be an identifier.

## Not in this release

Luma and inverted mattes, a feather property, and Lottie/SVG mask import. `compositing.mask` is unchanged.
