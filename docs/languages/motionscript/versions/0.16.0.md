# MotionScript 0.16.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "compositing.mask"` (the compiler adds it when a group carries `clip`). A package that does not enable that capability rejects the document at accept time. Decision: `docs/decisions/engine/scoped-clip-compositing.md` (E012).

## Capabilities introduced

- compositing.mask

## Syntax

`clip` is a new reserved word used as a group property. Clip geometry ids stay ordinary identifiers.

```
group Card {
  clip Window;
  rectangle Panel { size (200, 120); fill #334155; };
};
circle Window {
  position (100, 60);
  radius 48;
  visible false;
};
```

- `clip <geometryNodeId>;` on a `group` at most once (last write wins like other props).
- The target must be a `rectangle`, `circle`, `ellipse`, `polygon` or `path` in the same scene.
- Clip implies a compositing scope; `isolated` defaults to true when omitted (same pattern as blend/blur).
- Dedicated clip shapes usually set `visible false` so they do not paint; a visible clip source still paints and is itself clipped when nested under the group.

## Semantics

The group's render scope is intersected with the target node's resolved outline in viewport space. Nested clipped groups compose by successive intersection. Hit-testing rejects pointers outside every ancestor clip. Spatial seam fragments remain inside their compositing scope. Track mattes, alpha/luma masks, feathering and inverted clips are outside this release.

## Readers

A 0.16 consumer accepts wire `"0.2"` documents. Clip requires `compositing.mask` in `requires`. Older packages reject the capability token and the unknown `clip` compositing field. Programs without it compile exactly as in 0.15.0, except that `clip` is now reserved and cannot be an identifier.

## Not in this release

`compositing.matte`, feathered or inverted masks, offscreen isolated blend layers, and Lottie/SVG mask import. Other pending ids remain outside this file.
