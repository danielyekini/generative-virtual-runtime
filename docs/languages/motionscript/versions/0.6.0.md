# MotionScript 0.6.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "entities.durableRevisions"`. A 0.5.0 package without the capability does not accept entity-patch authorship that declares the requirement.

## Capabilities introduced

- entities.durableRevisions

## Syntax / authorship

This release recognises `requires "entities.durableRevisions"` and pairs with Scene IR `APPLY_ENTITY_PATCH` deltas. Hosts and the compiler emit those deltas through `emitEntityPatchDelta` in `@gvr/compiler`. Declarative MotionScript `entity` / `behaviour` statement productions remain open follow-up work; they are not claimed here.

## Readers

A 0.6 consumer accepts wire `"0.2"` documents. Durable entity patches require `entities.durableRevisions` in `requires`. There is no lossless down-conversion that drops post-seal topology edits into append-only sealed streaming.

## Not in this release

Other pending ids remain outside this file. Adapter coverage is in the registry.
