# MotionScript 0.9.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for declarative entity authorship sugar over released
0.6–0.7 Scene IR ops. Programs still declare `version "0.2"` and gate with
`requires "entities.durableRevisions"` and, for geometry register/bind,
`requires "entities.drawableBindings"`. No new capability token.

## Capabilities completed

- entities.durableRevisions (declarative `entity` / `behaviour` / `remove` / `reparent` / `cancel`)
- entities.drawableBindings (declarative `geometry` / `bind`)

## Syntax

```
geometry pane {
  space world;
  at 0ms;
  rectangle pane { size (20, 40); fill #3366cc; };
};
entity window_a {
  kind drawable;
  label "left";
  at 0ms;
};
bind window_a to pane at 0ms;
behaviour spin on room.spin.transform.rotation {
  activate at 500ms;
};
cancel behaviour spin;
remove entity room.roof at 500ms;
reparent room.pillar under room at 500ms;
```

Statements lower 1:1 onto `APPLY_ENTITY_PATCH` ops. Activation times must be
`>=` the sealed left-limit. Hosts may still use `emitEntityPatchDelta`.

## Readers

A 0.9 consumer accepts wire `"0.2"` documents. Older packages without these
capability tokens reject programs that declare them. There is no lossless
down-conversion that expands declarative statements into private node copies.

## Not in this release

Writable shared geometry, nested geometry assets, and whole-colour track types
remain outside this file.
