# MotionScript 0.12.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "space.planar25d"` (the compiler adds it when a `spatialLayer` declaration lowers). A package that does not enable that capability rejects the document at accept time. Decision: `docs/decisions/engine/spatial-graphics.md` (E010); versioning E028.

## Capabilities introduced

- space.planar25d

## Syntax

`spatialLayer` is the only new reserved word. `camera`, `surface` and every body word (`projection`, `perspective`, `orthographic`, `position`, `yaw`, `pitch`, `roll`, `focalLength`, `zoom`, `near`, `parent`, `pivot`, `rotation`, `scale`, `hinge`, `backface`, `visible`, `hidden`, `backFill`) are matched by spelling and stay usable as identifiers elsewhere.

```
spatialLayer orbit {
  camera {
    projection perspective;
    position (200, 150, -1000);
    yaw 0.2;
    pitch -0.1;
    focalLength 1000;
  };
  surface wall {
    position (0, 0, 40);
  };
  surface door {
    parent wall;
    hinge (0, 0) (0, 80) 0.5;
    backface hidden;
    backFill #223344;
  };
};
```

- `spatialLayer <id> { … };` declares one planar 2.5D layer with exactly one `camera { … };` block and any number of `surface <node> { … };` blocks.
- Camera: `projection perspective|orthographic;` (required), `position (x, y, z);`, `yaw|pitch|roll <angle>;` (radians as a bare number or an angle token such as `10deg`), `focalLength n;` and `near n;` (perspective), `zoom n;` (orthographic). `focalLength`, `zoom` and `near` must be greater than 0.
- Surface: names a root-scene node. Body: `parent <surface-node>;` (a surface of the same layer), `position|pivot|rotation|scale (x, y, z);`, `hinge (x, y) (x, y) <angle>;` (a line in the parent surface's plane and a rotation about it; the two points must differ), `backface visible|hidden;`, `backFill <colour>;` (reverse-face solid fill).
- A node is a surface of at most one layer. Layer ids are unique. A scene holds at most 1024 surfaces.
- Surfaces may precede their node; the declaration waits for it and an unresolved node reports `UNKNOWN_TARGET`. A layer is a base definition: it is frozen after the first `seal`.

## Semantics

Projection, depth ordering, back-face culling, near culling and input unprojection follow the E010 decision and the `@gvr/runtime` `projectSpatialFrame` contract. This release defines the syntax, the Scene IR it lowers to and the validation bounds.

## Readers

A 0.12 consumer accepts wire `"0.2"` documents. Spatial layers require `space.planar25d` in `requires`. Older packages reject `spatialLayer` as an unexpected declaration. Programs without it compile exactly as in 0.11.0, including identifiers spelled like camera or surface body words.

## Not in this release

Animated spatial channels (`z`, x/y rotations, hinge angle, camera values), input unprojection and surface drag bindings, intersection splitting and perspective clipping, and surfaces for composition nodes. Other pending ids remain outside this file.
