# MotionScript 0.7.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "entities.drawableBindings"` (alongside `entities.durableRevisions` when emitting entity patches). A 0.6.0 package without the capability does not accept drawable-binding authorship that declares the requirement.

## Capabilities introduced

- entities.drawableBindings

## Syntax / authorship

This release recognises `requires "entities.drawableBindings"` and pairs with Scene IR `REGISTER_GEOMETRY` / `BIND_GEOMETRY` ops on `APPLY_ENTITY_PATCH`. Hosts and the compiler emit those deltas through `emitEntityPatchDelta` in `@gvr/compiler`. Declarative MotionScript entity / bind / geometry-asset statement productions remain open follow-up work (E006); they are not claimed here.

## Readers

A 0.7 consumer accepts wire `"0.2"` documents. Drawable bindings require `entities.drawableBindings` in `requires`. There is no lossless down-conversion that expands shared geometry into private node copies for older readers.

## Not in this release

Other pending ids remain outside this file. Adapter coverage is in the registry. Mutable shared geometry and nested geometry assets remain out of scope.
