# MotionScript 0.10.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "input.bindings"` (the compiler adds it when an `interact` declaration lowers). A package that does not enable that capability rejects the document at accept time. Decision: `docs/decisions/engine/native-input.md` (E007); implementation E025.

## Capabilities introduced

- input.bindings

## Syntax

`interact` is the only new reserved word. Words inside an `interact` body (`on`, `click`, `drag`, `set`, `toggle`, `dragTranslate`, `focusable`, `tabIndex`, `pointer`, …) are matched by spelling and stay usable as identifiers elsewhere.

```
interact Knob {
  focusable true;
  tabIndex 0;
  on drag dragTranslate (20, 20) (380, 280);
  on wheel step scale.x 0.25 0.5 2;
  on key "ArrowRight" step position.x 10 20 380;
};
interact Panel { focusable true; on click toggle Glass.opacity 0.3 0.9; };
interact Glass { pointer none; };
```

- Target: a root-scene node id (dotted path allowed). One `interact` per node. Forward references wait for the node; unresolved targets report `UNKNOWN_TARGET`.
- Properties: `focusable true|false`, `tabIndex <integer>`, `pointer auto|none`.
- Bindings: `on click|activate|wheel <action>`, `on key "<KeyboardEvent.key>" <action>`, `on drag dragTranslate (minX, minY) (maxX, maxY)`.
- Actions: `set <addr> v`, `toggle <addr> a b`, `step <addr> delta min max`, where `<addr>` is `[node.path.]channel` and channel is `position.x`, `position.y`, `rotation`, `scale.x`, `scale.y` or `opacity` (the target node when no prefix). `dragTranslate` is the only action for `on drag`, and only there.
- Every written channel is exclusively input-owned for the whole scene: an `animate` / `keyframes` track writing the same scalar is rejected (`OVERLAPPING_WRITERS`). Opacity values lie in `[0, 1]`; `step` needs `min <= max`.
- `interact` is a base definition: frozen after the first `seal`.

## Semantics

Hit-testing, capture, click/drag threshold, wheel stepping by sign, Tab order (`tabIndex`, then declaration order), Enter/Space activation running click bindings, event ordering, lifetime release and replay follow the E007 decision. `dragTranslate` converts viewport deltas into the node's parent space before clamping. Input-owned values start at the authored node base.

## Readers

A 0.10 consumer accepts wire `"0.2"` documents. Interactions require `input.bindings` in `requires`. Older packages reject `interact` as an unexpected declaration. Programs without `interact` compile exactly as in 0.9.0, including identifiers spelled like interaction words.

## Not in this release

Paint channels as input targets, multi-pointer/pinch gestures, text entry, clip/mask-aware hit regions, behaviour/physics priority over input and scripted actions. Other pending ids remain outside this file.
