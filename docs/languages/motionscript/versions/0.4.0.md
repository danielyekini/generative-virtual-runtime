# MotionScript 0.4.0

Published. Do not edit. Wire version `"0.2"`.

Minor bump below 1.0 for a new capability contract. Programs still declare `version "0.2"` and gate the new feature with `requires "paint.gradientStroke"`. A package that does not enable that capability rejects the document at accept time. A 0.3.0 package without the capability does not accept gradient stroke paints.

## Capabilities introduced

- paint.gradientStroke

## Syntax

`stroke` accepts the same paint forms as `fill`, including linear and radial gradients:

```
stroke linear (0, 0) (100, 0) 0 #ff00aa 1 #5500ff width 3 cap round;
```

Fill gradients do not imply stroke gradients. A stroke whose colour is a gradient requires `paint.gradientStroke`.

## Readers

A 0.4 consumer accepts wire `"0.2"` documents. Gradient strokes require `paint.gradientStroke` in `requires`. There is no lossless down-conversion that drops gradient strokes into solid strokes.
