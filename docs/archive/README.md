# Archive

This directory is for material that has left the active tree and is not an evaluation run.

Evaluation runs stay in `docs/evaluations/<run-id>/`. They are immutable. A later run supersedes an earlier one by being linked from `docs/evaluations/README.md`. It does not replace that run's report, manifest, results, or evidence.

Do not treat an archived note, or a historical evaluation, as the current language specification. Current support is `packages/schema/capabilities/registry.json` together with the current versions in `packages/schema/capabilities/releases.json`.
