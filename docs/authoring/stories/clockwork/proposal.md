# Clockwork: language proposal

Retrospective written after the implementation, as supplied, recorded 2026-10-29. Unevaluated; see the [index](../README.md#what-these-proposals-are). Its tables were flattened when pasted and are kept as received. The 35-second duration finding was resolved when the default budget was raised to 60s in commit `1f1e3de`.

Changes that raise the ceiling
A bounded repeater and a channel reference remove the two copies that dominated this film: the dial, and the spin law. A parameterized composition is what lets the next film be edited as MotionScript.

A counted repeater
One declaration places N copies on a circle or along a segment. The count is a constant, not a loop.

Sixty ticks, twelve numerals, jewel screws, and a finer tooth count without spending one node per mark. The dial already uses 72 line nodes for ticks.

Expressions that can read a channel
An expression may name another node’s sampled rotation, position, or opacity. Seek stays deterministic because it reads the same sample.

One spin law for the train. Arbors, the second hand, and a follower stay locked to their driver. The ratio bugs came from copying that formula by hand.

Compositions with parameters
Instance already exists, and it is not expanded. It accepts a time range and a position, not teeth, phase, or a rotation expression. Give a composition arguments and expand it.

One gear definition, five instances. The .ms file becomes the program a model can edit. The 1,100-line TypeScript builder stops being the template system.

Arc, annulus, and a dashed ring
First-class arc and ring geometry, plus a circular dash. Evenodd holes and four-cubic circles stay available for irregular shapes.

A plate, a bezel, a hairspring, and a 30-tooth wheel without hundreds of path commands. This film’s tooth outlines are 384 path lines.

Angles inside expressions
Allow 90deg in expression strings, and reject a keyword used as a node id with the reserved word named in the diagnostic.

Phases stop being raw radians next to deg tokens that are stored as radians. Stolen names fail at the identifier, not as a mysterious parse.

A 1280×720 preview and a rest-pose camera fit
Render the real viewport from the runtime. A camera fit uses the rest bounds of named nodes. It does not solve motion.

Cropped dials and captions on the title block show up in the same step as compile. Square thumbnails hid the framing.

An authored-film budget, written down
Keep the published 30s limit until a version note says otherwise. A later release can raise duration and node count together, with tests.

A 35-second brief fits. A denser dial fits. One film is evidence, not a reason to reinterpret the current contract.

Leave these out of the core
A general loop or function is a new execution model and needs its own design. A gear solver, and a clock package, can wait until a composition can take parameters. Do not raise the 30-second budget by editing the published contract in place.
