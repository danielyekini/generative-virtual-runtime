## Reproduce

```sh

GVR_PREVIEW_DIR=work/order-book-preview npx tsx fixtures/motionscript/stories/build-inside-an-order-book.ts
npm run typecheck
npx vitest run
npm run build -w @gvr/playground
```

Preview mode needs a discoverable Chromium binary or `GVR_CHROME` / `CHROME_PATH`, and the installed workspace dependencies. It uses production `CanvasRenderer` through a local Vite server and CDP. Without `GVR_PREVIEW_DIR`, the builder emits/compiles/validates/asserts the program and writes no preview stills.
