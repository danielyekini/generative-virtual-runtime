# Authoring documentation and agent update rules

Status: living supporting policy, revision 1.0, 2026-10-08.

## Edit permissions and authority

The operator permits agents to update all supporting authoring documents as analysis yields insights and successful approaches yield evidence. docs/workflows/authoring-loop.md is the exception: ordinary runs must not edit its process contract. Workflow changes require explicit operator direction and a recorded new revision.

Living goals, guide, evolution rubric, evaluation specification, registry specification, templates, installation guidance and indexes can evolve without repeated permission. This does not authorise retroactive editing of published language versions, historical runs, verified original sample bytes or frozen benchmark manifests. Those remain immutable under existing repository rules. Agent permission to document findings is not permission to release new semantics or publish remotely beyond the task's authorised scope.

## Evidence-backed edits

For each substantive update record revision/date, concise change, rationale, run/proposal evidence, measured scope, confidence and counterexamples. Label untested insights hypotheses. An analysis-only insight can be documented without claiming successful evaluation. Maintain terminology and relative links. Add a later correction rather than erasing negative evidence.

Separate evidence from guidance: run directories freeze what happened; living documents explain the current interpretation. If evaluation methods change, create a new benchmark/protocol revision and rerun comparisons. Never change a running acceptance bound to fit a candidate. Agents may propose and adopt future supporting measurement improvements with rationale; they must not weaken the workflow quality invariant.

## Source of truth

Grammar/schema: accepted syntax and representation. Registry: current support claims. Published language versions: release history. Fidelity policy and pinned task requirements: quality criteria. Authoring workflow: process. Supporting guides: revisable interpretation. Run reports: revision-specific evidence.
