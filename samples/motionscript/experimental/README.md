# Experimental program class

Isolated experiments with hashes and provenance; promotion creates a new immutable canonical revision.

This directory describes the class; actual programs belong under `samples/motionscript/<sample-id>/experimental/` as defined in the [storage specification](../../../docs/authoring/sample-registry-spec.md). Installation creates no sample IDs or program revisions. Keep original bytes and manifests immutable; update registry pointers only with rationale and evidence.
