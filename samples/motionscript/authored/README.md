# Authored program class

Refinement variants, preserving their faithful parent and independently re-verified against original requirements.

This directory describes the class; actual programs belong under `samples/motionscript/<sample-id>/authored/` as defined in the [storage specification](../../../docs/authoring/sample-registry-spec.md). Installation creates no sample IDs or program revisions. Keep original bytes and manifests immutable; update registry pointers only with rationale and evidence.
